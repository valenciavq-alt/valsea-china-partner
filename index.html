VALSEA Speech API
VALSEA 语音 API

A single REST API for transcription, semantic extraction, and structured output — deployable in any corridor with data residency compliance.

一个统一的 REST API，覆盖转录、语义提取及结构化输出——可在任何走廊部署，满足数据本地化合规要求。

🎯

POST /v1/transcribe

Real-time and batch speech-to-text. Accent profile selection. <500ms latency.

实时及批量语音转文字。口音配置选择。延迟低于 500ms。

💡

POST /v1/understand

Semantic extraction: topics, action items, entities, sentiment. Handles mixed-language natively.

语义提取：主题、行动项、实体、情感分析。原生支持混合语言。

📄

POST /v1/output

Formatted deliverables: meeting notes, compliance reports, .srt subtitles, custom templates.

格式化交付物：会议纪要、合规报告、.srt 字幕、自定义模板。
