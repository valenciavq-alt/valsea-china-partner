## 4. Pilot Offer: China–Africa On-Site Speech Intelligence

### Pilot Summary

> **"Mandarin ↔ Local Language Speech Intelligence for Chinese-Invested Operations in Africa"**
>
> A 4-week paid pilot ($5,000–$10,000) proving VALSEA's ability to transcribe, translate, and structure multilingual voice data from real on-site operations — construction meetings, BPO calls, logistics coordination — where no global ASR provider can deliver.

### What the Pilot Covers

1. **Setup (Week 1):** API credentials, corridor configuration (Mandarin↔Swahili/Amharic/English), accent profile calibration, integration with existing call recording or meeting platform.

2. **Live Transcription (Week 2–3):** Process real audio from daily operations — minimum 50 hours of mixed-language recordings. Deliver structured outputs: transcripts, meeting notes, action items, compliance-ready documents in both languages.

3. **Accuracy Benchmarking (Week 3):** Head-to-head comparison vs. Google Cloud Speech / Azure / AWS on the same audio corpus. Measure WER on code-switched segments specifically.

4. **Results & Handoff (Week 4):** Deliver accuracy report, integration documentation, and production deployment plan. Decision point: convert to annual contract or walk away.

### Pilot Pricing

| Tier | Scope | Price |
|---|---|---|
| Starter | Single site, 50 hrs audio, 1 language pair | $5,000 |
| Standard | Multi-site, 200 hrs audio, 2–3 language pairs | $10,000 |
| Enterprise | Custom scope, on-premise option, SLA guarantee | Custom |

### What Makes This Different

- **Mandarin↔Swahili pipeline:** Does not exist at Google, Azure, or AWS. Zero-competition positioning.
- **African accent handling:** 11–18% WER vs. 20–50% for incumbents (via Intron Health Sahara v-2 integration).
- **Structured output:** Not raw transcription — meeting notes, compliance docs, action items ready for workflow integration.
- **Data residency:** China-compliant deployment available (audio stays in-region).

## 5. Success Metrics for Initial Pilots

### Primary Metrics

| Metric | Target | How Measured |
|---|---|---|
| **WER on code-switched segments** | ≤15% on Mandarin↔Swahili; ≤18% on Mandarin↔African-accented English | Side-by-side human evaluation on 100+ utterances with code-switching |
| **WER improvement vs. incumbents** | ≥50% relative improvement over Google/Azure/AWS on same corpus | Paired test: same audio, same segments, WER comparison |
| **Reduction in manual validation time** | ≥60% reduction in human review/correction time vs. current workflow | Time-on-task measurement: hours spent correcting ASR output pre/post VALSEA |
| **Time-to-deploy integration** | ≤5 business days from API key to first structured output in production | Calendar days from credentials issued to first successful API call returning structured output |

### Secondary Metrics

| Metric | Target | How Measured |
|---|---|---|
| Latency (real-time mode) | <500ms end-to-end | API response time P95 |
| Uptime during pilot | ≥99.5% | Monitoring dashboard |
| User satisfaction (if applicable) | ≥4/5 from end-users interacting with outputs | Survey at pilot end |
| Cost per audio hour | ≤$2.50/hr processed | Usage billing |
| Structured output accuracy | ≥90% of action items correctly extracted | Human spot-check on 50 documents |

### Pilot-to-Contract Conversion Criteria

The pilot converts to an annual contract if:
1. WER on code-switched segments meets target (≤15% / ≤18%)
2. Manual validation time reduction exceeds 50%
3. Integration deployed within 5 business days
4. Stakeholder sign-off from operations lead AND IT/compliance
